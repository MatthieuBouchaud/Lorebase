# Brain

This is a blank personal brain repo.

Start here:

1. Read `AGENTS.md`.
2. Read `RESOLVER.md`.
3. Put quick, unsorted captures in `inbox/`.
4. Promote durable knowledge to the resolver-selected directory.
5. Run `gbrain import . --no-embed` or `gbrain sync --repo .` after meaningful changes.

The important invariant: one durable thing gets one primary page. Cross-links preserve relationships without duplicating source of truth.
