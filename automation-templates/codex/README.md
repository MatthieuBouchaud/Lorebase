# Codex Automation Templates

These templates are rendered by `scripts/bootstrap.sh` into `generated/codex-automations/`.

Placeholders:

- `{{STARTER_REPO}}`
- `{{GBRAIN_REPO}}`
- `{{BRAIN_REPO}}`
- `{{CODEX_SKILL_PATH}}`
- `{{MODEL}}`

Rendered automations are paused by default. Enable them one source at a time after connector setup and a manual test run.
